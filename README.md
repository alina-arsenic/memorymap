# MemoryMap

**MemoryMap** — веб-приложение и Telegram-бот для хранения значимых мест на карте: с заметками, фотографиями и привязкой к аккаунту.

Проект позволяет:

- добавлять точки на карте через веб-интерфейс и Telegram-бота;
- прикреплять фотографии (S3/MinIO) с автогенерацией миниатюр;
- редактировать названия и описания;
- организовывать точки по слоям (публичный, личный, групповой);
- добавлять друзей и приглашать их в совместные слои;
- оставлять комментарии к точкам с вложенными ответами;
- получать уведомления о событиях (дружба, комментарии, приглашения);
- блокировать нежелательных пользователей;
- подавать жалобы на неуместный контент;
- управлять доступом через авторизацию с email-подтверждением;
- привязывать Telegram-аккаунт к профилю;
- восстанавливать и менять пароль, логин, email.

## Возможности

### Пользователи и авторизация

- Регистрация по логину, email и паролю (пароль хранится в хеше, min 8 символов).
- Подтверждение email: 6-значный код отправляется через SMTP, без подтверждения вход невозможен.
- Повторная отправка кода подтверждения, срок действия кода — 10 минут.
- Вход / выход, JWT access-token.
- Восстановление пароля: код на email → сброс пароля.
- Смена пароля, логина, email (с подтверждением кодом).
- Инвалидация старых JWT-токенов при смене пароля.
- Привязка/отвязка Telegram-аккаунта через deep link (`t.me/BOT?start=CODE`) или команду `/link`.
- Удаление аккаунта с подтверждением паролем (каскадное удаление данных).

### Роли и управление пользователями

- Три роли: `admin`, `moderator`, `user`.
- Первый зарегистрированный пользователь автоматически становится `admin`.
- Администратор может назначать и снимать роль `moderator` через панель управления.
- При назначении роли `moderator` все pending-точки пользователя автоматически одобряются.
- Администратор видит PII (email, tg_id) в панели; модератор — только login и роль.
- Панель управления пользователями с поиском по логину и email (только для admin).

### Работа с картой

- Просмотр публичных и своих точек.
- Добавление точки кликом правой кнопкой мыши (на мобильных — long press).
- Автогенерация названия по координатам, если оно пустое.
- Редактирование названия, заметки и фотографий (через форму в боковой панели).
- Удаление своих точек (admin/moderator могут удалить любую через API).
- Шеринг точки по ссылке (`?place=ID`).
- Галерея фото с полноэкранным просмотром и навигацией.
- Сворачиваемый sidebar.

### Премодерация публичных точек

- Публичные точки от обычных пользователей создаются со статусом `pending`.
- Точки от admin/moderator сразу получают статус `approved`.
- На карте: автор видит свои pending-точки (серый пин + плашка «На модерации»).
- Admin/moderator видят все pending-точки на карте.
- Панель модерации в sidebar: превью фото (до 3 шт.), обрезанное описание (до 100 символов).
- Кнопка «Показать на карте» перемещает карту к точке и открывает её карточку.
- Модератор может одобрить или отклонить точку.

### Жалобы (постмодерация)

- Пользователь может пожаловаться на одобренную точку (категории: спам, оскорбления, неверная локация, приватность, другое).
- Повторная жалоба от того же пользователя запрещена.
- Жалобы отображаются в панели модерации.
- При одобрении/отклонении точки — жалобы автоматически резолвятся.

### Слои (группы)

- Публичный слой — точки видны всем пользователям (с премодерацией).
- Личный слой — создаётся автоматически, точки видны только автору.
- Групповые слои — пользователь может создавать свои слои и приглашать друзей.
- Роли участников слоя: владелец (owner), редактор (editor — может добавлять точки), наблюдатель (viewer — только просмотр).
- Переключение видимости слоёв на карте через плавающую кнопку или на боковой панеле в табе "Слои".
- Выбор слоя при добавлении точки (на вебе и в боте).

### Друзья

- Поиск пользователей по логину.
- Отправка и приём запросов дружбы.
- Взаимный запрос дружбы → автоматическое принятие.
- Уведомления о входящих запросах.
- Удаление из друзей.

### Блокировка пользователей

- Блокировка нежелательных пользователей.
- Блокировка автоматически удаляет дружбу и отменяет pending-запросы.
- Заблокированные пользователи не могут отправить запрос дружбы.

### Комментарии

- Комментарии к точкам в публичных и групповых слоях (запрещены в личных).
- Вложенные ответы (один уровень).
- Редактирование комментария автором (в течение 1 часа).
- Удаление: автор, владелец точки, admin/moderator.
- Уведомления о новых комментариях.

### Уведомления

- Уведомления о событиях: комментарии, ответы, запросы дружбы, приглашения в группы.
- Пометка прочитанными (одно или все).
- Счётчик непрочитанных в шапке сайта (бейдж на иконке "колокольчик").

### Приглашения в группы

- Приглашение друзей в групповой слой с назначением роли.
- Принятие / отклонение / отмена приглашения.
- Список входящих и исходящих приглашений.

### Медиа (фото)

- До **12 фотографий на одну точку**.
- Загрузка через presigned URL (MinIO / S3).
- Автоматическая генерация миниатюр (Pillow).
- Форматы: JPG, JPEG, PNG, GIF, WebP.
- Добавление фото к существующей точке.
- Удаление фотографий.
- Просмотр фото в полноэкранном режиме.

### Telegram-бот

- Добавление точек отправкой геолокации с выбором слоя.
- Добавление названия, описания и фото к точке через бота.
- Редактирование и удаление точек.
- Создание новых слоёв.
- Привязка/отвязка Telegram ID к аккаунту через deep link или команду `/link`.
- Username бота определяется автоматически через Telegram API (`getMe`).
- Безопасное взаимодействие с API через `X-Bot-Secret`.

## Стек технологий

**Backend**

- Python 3.11, FastAPI, SQLAlchemy
- PostgreSQL 15 + PostGIS 3.3
- MinIO (S3-совместимое хранилище)
- JWT (access token), passlib / bcrypt
- Pillow (генерация миниатюр)
- smtplib (отправка email)

**Frontend**

- Vanilla JS, MapLibre GL JS
- HTML + CSS (адаптивный дизайн)

**Telegram-бот**

- Python 3.11, aiogram 3.4.1

**Инфраструктура**

- Docker, Docker Compose (локальная разработка)
- K3s (продакшен-деплой)
- GitHub Actions (CI: Ruff + ESLint + pytest)

## Запуск проекта

### 1. Подготовка окружения

```bash
cp .env.example .env
```

Заполните в `.env`:

- `TELEGRAM_BOT_TOKEN` и `BOT_API_SECRET` — для работы бота
- `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_FROM` — для отправки email с кодами подтверждения
- `JWT_SECRET` — секретный ключ для JWT (не использовать значение по умолчанию в продакшене)

### 2. Запуск

```bash
docker compose up -d --build
```

После запуска:

- Web UI: http://localhost:8000
- MinIO Console: http://localhost:9001
- PostgreSQL: localhost:5432

## Безопасность и ограничения

- Пароли хранятся только в виде хеша (bcrypt).
- JWT access token с ограниченным сроком жизни.
- Инвалидация токенов при смене пароля (`tokens_valid_after`).
- Email подтверждается 6-значным кодом (срок действия — 10 минут).
- Медиа-операции защищены авторизацией и проверкой владельца.
- Telegram-бот общается с API только через `X-Bot-Secret`.
- Лимит: **12 фото на точку** (проверяется и на фронте, и на бэке).
- Роль `admin` нельзя назначить через интерфейс (только первая регистрация).
- XSS-защита: все пользовательские данные экранируются через `escapeHtml()`.
- Валидация: temp_key для S3, координаты, длина title/note/comment.

## Типовые сценарии использования

### Регистрация и вход

1. Откройте http://localhost:8000 (или https://memory-map.ru).
2. Нажмите кнопку **«Регистрация»** в шапке сайта.
3. Заполните логин, email, пароль и подтверждение пароля (минимум 8 символов).
4. На указанный email придёт 6-значный код подтверждения — введите его в форму.
5. После подтверждения email нажмите **«Войти»** в шапке и введите логин и пароль.

### Добавление точки через веб-интерфейс

1. Авторизуйтесь на сайте.
2. Кликните правой кнопкой мыши на нужное место на карте (на мобильных — долгое нажатие). Появится жёлтый пин.
3. В боковой панели → вкладка «Место» заполните название, описание, загрузите фотографии.
4. Выберите слой (группу) и нажмите **«Добавить точку»**.

### Привязка Telegram и добавление точки через бота

1. В шапке нажмите на своё имя → **«Настройки»** → раздел **«Telegram»** → **«Подключить»**.
2. Перейдите по появившейся ссылке — она откроет бота в Telegram (или отправьте боту `/link КОД`).
3. Бот привяжет ваш Telegram-аккаунт к профилю.
4. Отправьте боту геолокацию (кнопка «Поделиться местоположением»).
5. Бот предложит выбрать слой — нажмите нужную кнопку.
6. Точка создана. Бот предложит добавить название, описание и фото.

### Создание группового слоя и приглашение друзей

1. В боковой панели → вкладка «Слои» → нажмите **«+ Новый слой»**, введите название.
2. Новый слой появится в списке — нажмите на него, чтобы раскрыть настройки.
3. Найдите пользователя по логину во вкладке «Друзья», отправьте запрос дружбы.
4. После принятия запроса — пригласите друга в слой, выбрав роль editor (редактор) или viewer (наблюдатель).
5. Редакторы могут добавлять точки в общий слой, наблюдатели — только просматривать.

### Модерация точек (для admin/moderator)

1. Публичные точки от обычных пользователей попадают на модерацию.
2. В sidebar откройте панель «Модерация» — там отображается очередь точек с жалобами.
3. Для каждой точки доступен предпросмотр: автор, координаты, описание, до 3 фото.
4. Нажмите «Показать на карте», чтобы перейти к точке и увидеть её карточку.
5. Одобрите или отклоните точку.

## Типовые ошибки и решения

### Ошибка: контейнеры не стартуют

```bash
docker compose down
docker compose up -d --build
```

Если проблема с портами — убедитесь, что порты 5432, 8000, 9000, 9001 свободны.

### Ошибка: "No module named 'app'"

При запуске тестов убедитесь, что вы в директории `backend/`:

```bash
cd backend
pytest -v
```

### Фото не загружаются (MinIO)

Убедитесь, что переменные S3 в `.env` корректны:

```
S3_ENDPOINT=http://minio:9000
S3_ACCESS_KEY=minioadmin
S3_SECRET_KEY=minioadmin
S3_BUCKET=memorymap-media
```

### Email с кодом не приходит

Проверьте SMTP-настройки в `.env`. Для тестирования можно использовать Mailtrap или другой SMTP-сервис для разработки.

### ESLint ошибки "no-undef"

Frontend использует глобальные переменные (`maplibregl`, `fetch`, `alert`). Они описаны в `.eslintrc.json` → `globals`.

## Статус проекта

**MUP**

Реализован полный функционал MUP: авторизация с подтверждением email, восстановление и смена пароля/логина/email, карта с точками и фотогалереей, комментарии, уведомления, Telegram-бот, групповые слои с приглашениями, друзья и блокировка, премодерация и постмодерация (жалобы), роли и управление пользователями, удаление аккаунта.

Продакшен-версия развёрнута на https://memory-map.ru (K3s).
